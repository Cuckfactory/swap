CUCK BAG RECYCLER V5 - HOW TO OPEN

IMPORTANT: do NOT double-click index.html.
V5 contains the real embedded LI.FI React widget, so the source must be built/run by Vite.
Opening index.html as a local file (file:///C:/...) gives a blank page.

WINDOWS QUICK START
1. Install Node.js LTS once: https://nodejs.org/
2. Unzip this folder.
3. Double-click START_WINDOWS.bat.
4. On first run it installs the required packages.
5. It opens http://127.0.0.1:5173/ automatically.

Test an existing Employee wallet by opening:
http://127.0.0.1:5173/?wallet=0xYOUR_EVM_WALLET

For production this will be built/deployed normally and users will never need Node or these steps.
